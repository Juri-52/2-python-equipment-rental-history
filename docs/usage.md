# 使い方

リポジトリのルートで `python main.py` を実行すると、以下のメニューが表示されます。
```
1. 一覧  2. 検索  3. 貸出  4. 返却  5. 貸出可のみ  0. 終了
番号を選択:
```
ここから各操作を実行することができます。  
番号の選択は`0`～`5`の半角数字によってのみ行われ、それ以外の入力はエラーになります。
```
【1. 一覧】
備品を一覧表示します。

---表示例---
E001 ノートPC A / 貸出可
E002 ノートPC B / 貸出中（佐藤）
E003 デジタルカメラ / 貸出可
E004 三脚 / 貸出可
E005 プロジェクター / 貸出中（鈴木）
E006 ワイヤレスマイク / 貸出可
E007 タブレット / 貸出可
E008 モバイルルーター / 貸出可
```
```
【2. 検索】
備品を備品番号から検索します。
完全一致検索になります。

---表示例---
・検索成功時
E001 ノートPC A / 貸出可

・検索失敗時
操作できません: 指定した番号の備品が見つかりません
```
```
【3. 貸出】
備品を貸出します。
備品番号と利用者名を入力します。
貸出状態は保存され、返却するまで貸出できなくなります。
アプリケーションの再起動後も貸出状態は保存されます。

---表示例---
・貸出成功時
貸出を記録しました。

・貸出失敗時
操作できません: 指定した番号の備品が見つかりません
操作できません: この備品は貸出中です
操作できません: 利用者名を入力してください
```
```
【4. 返却】
貸出された備品を返却します。
備品番号を入力します。

---表示例---
・貸出成功時
返却を記録しました。

・貸出失敗時
操作できません: 指定した番号の備品が見つかりません
操作できません: この備品は貸し出されていません
```
```
【5. 貸出可のみ】
貸出可能な備品のみに絞り込み、一覧表示します。

---表示例---
E001 ノートPC A / 貸出可
E003 デジタルカメラ / 貸出可
E004 三脚 / 貸出可
E006 ワイヤレスマイク / 貸出可
E007 タブレット / 貸出可
E008 モバイルルーター / 貸出可
```
```
【0. 終了】
アプリケーションを終了します。
このコマンドが選択されるまで、各コマンドの実行後やエラーの発生後もメニュー画面が再表示されます。
```
